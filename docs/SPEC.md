## 1. 🎯 Цели и позиционирование

**Продукт:** Time Saver AI — персональный бренд специалиста по разработке ИИ-агентов.

**Главная идея:** Автоматизирую повседневные задачи → клиент освобождает время для главного.

**Целевая аудитория:** малый бизнес, фрилансеры, эксперты без IT-бэкграунда. Понятный язык, акцент на выгоде.

**Стек:** статичный сайт (HTML + CSS + минимальный JS) — для простоты размещения на GitHub Pages / Vercel.

**Структура файлов (по правилам `claude.md`):**

```
time-saver-ai/
├── index.html       ← в корне
├── style.css        ← в корне
├── main.js          ← в корне
├── assets/          ← изображения, иконки
├── docs/            ← документация (SPEC.md здесь)
└── reports/         ← отчёты
```

## 4. 🎨 Дизайн-система

### Цветовая палитра

| Роль | Цвет | HEX | Использование |
|------|------|-----|---------------|
| **Фон основной** | Белый | `#FFFFFF` | Базовый фон секций |
| **Фон вторичный** | Светло-серый | `#F7F9FC` | Альтернативные секции |
| **Фон акцентный** | Светлый teal | `#E6FFFA` | Секция кейса (подложка) |
| **Текст основной** | Тёмно-серый | `#1A2332` | Заголовки, основной текст |
| **Текст вторичный** | Серый | `#6B7785` | Подзаголовки, описания |
| **Акцент (primary)** | **Teal** | **`#0EA5A4`** ✅ | Кнопки, ссылки, иконки |
| **Акцент (hover)** | Тёмный teal | `#0D8B8A` | Наведение на кнопки |
| **Граница** | Светло-серая | `#E5E9F0` | Карточки, разделители |
| **Белый текст** | Белый | `#FFFFFF` | Текст на teal-фоне (CTA-секция) |

### Типографика

- **Шрифт:** Inter (Google Fonts), с fallback на системный sans-serif
- **Заголовки:** Inter (700, 800)
- **Текст:** Inter (400, 500)
- **Кнопки:** Inter (600)

**Размеры:**

- H1 (hero): 56–64px (desktop), 36–40px (mobile)
- H2 (секции): 36–40px (desktop), 28–32px (mobile)
- H3 (карточки): 20–24px
- Основной текст: 16–18px
- Мелкий текст: 14px

### Пространство и сетка

- **Контейнер:** max-width 1200px, по центру
- **Отступы между секциями:** 96–120px (desktop), 64px (mobile)
- **Внутренние отступы секций:** 24px (mobile), 32px (desktop)
- **Скругления:** 12–16px для кнопок и карточек
- **Тени:** минимальные, только для интерактивных элементов

### Анимации

- Плавное появление элементов при скролле (fade-in + slide-up)
- Hover-эффекты на кнопках (смена цвета за 200ms, лёгкий scale 1.02)
- Плавный скролл по якорям
- Без сложных 3D/видео — лёгкость важнее
